# Jobis Bijo — Portfolio

Personal portfolio website for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — visual design and responsive layout
- `script.js` — small navigation/scroll interaction
- `Jobis_Bijo_Resume.pdf` — add your resume PDF here

## Publish with GitHub Pages

1. Create a GitHub repository named `me-jobis.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and your resume PDF.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site should become available at `https://me-jobis.github.io`.

If your GitHub username is different, use:
`https://YOUR-USERNAME.github.io`
